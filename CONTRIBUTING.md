# Guia de Contribuição

Obrigado por considerar contribuir para este projeto! 🎉

## Como contribuir

### 1. Prepare seu ambiente

- **Crie um fork** do repositório
- **Clone** seu fork para sua máquina local

### 2. Desenvolva sua contribuição

- **Crie uma branch** para sua feature ou correção:

  ```bash
  git checkout -b minha-feature
  ```

- **Faça commits claros e descritivos** usando Conventional Commits:

  ```bash
  git commit -m "feat: adiciona funcionalidade X"
  ```

### 3. Envie sua contribuição

- **Envie sua branch** para seu fork:

  ```bash
  git push origin minha-feature
  ```

- **Abra um Pull Request (PR)** incluindo:
  - Uma descrição clara do que foi alterado
  - Prints, exemplos ou testes quando aplicável

## Boas práticas

- Sempre mantenha sua branch atualizada com a main
- Adicione testes para novas funcionalidades
- Respeite o estilo de código definido no projeto (linters, formatação, etc.)
- Revise sua própria alteração antes de abrir o PR

## Fluxo de contribuição

1. Abra uma issue para discutir grandes mudanças antes de começar
2. Implemente as alterações na sua branch
3. Abra um PR e aguarde revisão
4. Ajuste o código caso haja feedback
5. Merge! 🚀
