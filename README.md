### 📌 Sobre o Projeto

O site do Partido Urubista foi desenvolvido para ser a presença digital oficial do movimento, fornecendo informações essenciais e possibilitando a filiação de novos membros. A plataforma oferece uma experiência intuitiva e informativa para visitantes interessados em conhecer mais sobre o partido.

### 🛠 Tecnologias

O projeto foi desenvolvido utilizando tecnologias modernas de desenvolvimento web:

- [TypeScript](https://www.typescriptlang.org/)
- [Next.js](https://nextjs.org/)
- [Node.js](https://nodejs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Prisma](https://www.prisma.io/)
- [Neon DB](https://neon.tech/)

### 📋 Requisitos

- Node.js (versão recomendada: 18.x ou superior)
- Gerenciador de pacotes (npm, yarn ou pnpm)
- Git

### 🚀 Instalação

Para instalar e executar o projeto localmente:

```bash
# Clone o repositório
git clone <link do repositório>

# Entre no diretório do projeto
cd site-pu

# Instale as dependências
npm install
# ou
yarn
# ou
pnpm install

# Inicie o servidor de desenvolvimento
npm run dev
# ou
yarn dev
# ou
pnpm dev
```

Para instruções mais detalhadas sobre como contribuir, consulte o arquivo [CONTRIBUTING.md](./CONTRIBUTING.md).

### 🖥 Estrutura do Site

O site é composto pelas seguintes seções principais:

- **Home**: Página inicial com visão geral do partido
- **História**: Origem e trajetória do movimento urubista
- **Influenciadores**: Pensadores e figuras importantes que moldaram a ideologia
- **Filiação**: Formulário para novos membros se juntarem ao partido

### 📌 About the Project

The Urubista Party website was developed to be the official digital presence of the movement, providing essential information and enabling the affiliation of new members. The platform offers an intuitive and informative experience for visitors interested in learning more about the party.

### 🛠 Technologies

The project was developed using modern web development technologies:

- [TypeScript](https://www.typescriptlang.org/)
- [Next.js](https://nextjs.org/)
- [Node.js](https://nodejs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Prisma](https://www.prisma.io/)
- [Neon DB](https://neon.tech/)

### 📋 Requirements

- Node.js (recommended version: 18.x or higher)
- Package manager (npm, yarn, or pnpm)
- Git

### 🚀 Installation

To install and run the project locally:

```bash
# Clone the repository
git clone <repository link>

# Enter the project directory
cd site-pu

# Install dependencies
npm install
# or
yarn
# or
pnpm install

# Start the development server
npm run dev
# or
yarn dev
# or
pnpm dev
```

For more detailed instructions on how to contribute, see the [CONTRIBUTING.md](./CONTRIBUTING.md) file.

### 🖥 Website Structure

The website consists of the following main sections:

- **Home**: Main page with an overview of the party
- **History**: Origin and trajectory of the Urubista movement
- **Influencers**: Thinkers and important figures who shaped the ideology
- **Membership**: Form for new members to join the party
